About StreamPulse

StreamPulse is an ultra-fast, mobile-first video streaming web platform built with a zero-server static architecture specifically designed for direct hosting on Server, Cloudflare Pages, or any static CDN.

Engineered for Mobile Performance

Unlike heavy single-page apps burdened by massive JavaScript runtimes and server dependencies, StreamPulse utilizes lightweight semantic HTML5, high-efficiency CSS, and vanilla JavaScript. This guarantees near-instant First Contentful Paint times and fluid 60FPS mobile browsing even over cellular connections.

Key Capabilities

  • Multi-Source Video Engine: Native support for HTML5 direct MP4 streams, YouTube embeds, Videy.co embeds, and third-party iframe providers.
  • Centralized Adsterra Monetization: Isolated ad slots with timed in-player overlays, responsive banner containers, and effortless publisher configuration.
  • Bilingual i18n System: Seamless language switching between English and Indonesian with persistent user preferences.
  • Zero Backend Requirement: Operates entirely without Node.js server hosting, PHP, or relational databases.

Open Architecture & Extensibility

Managing videos, articles, and advertisement tags takes place within clean, structured JavaScript files (assets/js/videos.js and assets/js/ads.js). Adding or updating videos requires only adding an entry to the JSON array.
